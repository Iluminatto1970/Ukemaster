# 📱 Kit de Perfis — UkeMaster Pro

> Pasta com tudo que você precisa para criar os perfis de Instagram, TikTok, Facebook e YouTube.
> **Assets de logo disponíveis:** `public/logo.png` (principal), `public/favicon-180.png` (apple-touch, 180px — ideal para avatar).
> Site: https://ukemasterpro.vercel.app

## Arquivos desta pasta

| Arquivo | Conteúdo |
|---|---|
| `bios.md` | Textos de bio prontos para cada rede (várias opções) |
| `highlights.md` | Destaques do Instagram com nomes, capas e descrições |
| `avatar-instructions.md` | Como preparar a foto de perfil a partir da logo (com dimensões exatas) |
| `posting-kit.md` | Resumo rápido: links, hashtags e CTAs para copiar |

## Como usar

1. **Foto de perfil:** use `public/logo.png` (ou `favicon-180.png`) seguindo o passo a passo de `avatar-instructions.md`
2. **Bio:** escolha uma opção de `bios.md` por rede e cole
3. **Destaques (Instagram):** crie os destaques da lista de `highlights.md`
4. **Posts:** use os roteiros de `SOCIAL_CONTENT_PLAN.md` + o `posting-kit.md` para links/hashtags
