## 4. 📝 Roteiros prontos (copie e use)

### Roteiro 1 — "Cifra com 3 acordes" (Reels 25s)
```
[0-3s]  Toca o refrão da música no ukulele (gancho!)
[3-8s]  Texto na tela: "Não Quero Te Perder — Zezé, no ukulele 🎵"
[8-15s] Mostra os 3 acordes (diagrama do site): D - A - G
[15-20s] "Cifra completa GRÁTIS no UkeMaster Pro"
[20-25s] CTA: "Link na bio 👆" + aponta pro celular
Legenda: Música no tom D, cifra completa no site! 🎸 #ukulele #cifras
```

```
[0-3s]  "Quer tocar sertanejo no uke?"

[10-15s] Toca a música com o padrão aplicado
[15-20s] "Padrões prontos em cada cifra do site — link na bio"
```

```

[25-30s] "Grátis, direto no navegador — link na bio"
```
